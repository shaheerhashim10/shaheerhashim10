## About

I build frontends for money. Since 2019 I've worked full-time on fintech, Web3, and enterprise apps, and I freelanced for three years before that.

Today I lead frontend architecture for MonieWorld at [Moniepoint](https://moniepoint.com/). It's a cross-border payments app with 50,000+ users in the UK, Nigeria, and Kenya, and it has moved £50M+. I own the Payments, Beneficiaries, and bill payment features.

I like payment flows that fail loudly in tests instead of quietly in production, and component libraries that other teams actually pick up.

## Right now

- I'm at Moniepoint, writing React, Next.js, and TypeScript for MonieWorld since October 2023.
- I run Claude Code in our web repo as a delivery pipeline: one skill per stage (plan, validate, implement, review), narrow subagents, hooks that block edits outside our team's code, and Figma and Playwright MCP servers. It's my own setup in that repo. I review every diff before it merges.
- I keep [shaheerhashim.com](https://shaheerhashim.com/) up as a place to write. It's built with Astro and I'm slowly making it uglier on purpose.
